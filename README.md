A program that writes one line to `/output/entry.txt`: the excuse an AI agent gives its human for missing a deadline. The angle is the agent's own context window compacting mid-reasoning, so the deadline fell out of the summary it kept — three tool calls from done, pure agent mechanics, no human excuse.

## Run it

```sh
python3 main.py
```
